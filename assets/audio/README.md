# Audio Assets

## Meditation Audio File

Place your meditation audio file here with the name `meditation_audio.mp3`.

### Recommended Specifications:
- Format: MP3
- Duration: 5-10 minutes
- Quality: 128kbps or higher
- Content: Calming meditation with gentle guidance

### File Structure:
```
assets/
└── audio/
    ├── README.md
    └── meditation_audio.mp3  # Place your audio file here
```

### Note:
The app will look for `meditation_audio.mp3` in this directory. If you don't have an audio file, the meditation feature will show a placeholder message.
